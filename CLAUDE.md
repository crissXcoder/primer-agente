# Instrucciones para Asistentes y Claude Code

Este repositorio utiliza [`AGENTS.md`](./AGENTS.md) como fuente única de verdad para convenciones de código, flujos de verificación, modelo de datos y estándares de calidad.

Para cualquier tarea:
1. Revisa [`docs/SPEC.md`](./docs/SPEC.md) para requerimientos de negocio y frontmatter.
2. Consulta [`docs/DECISIONS.md`](./docs/DECISIONS.md) para decisiones técnicas y arquitectónicas.
3. Asegura que `pnpm typecheck`, `pnpm lint` y `pnpm build` pasen con éxito.
