Git es el sistema de control de versiones fundamental para clonar repositorios, colaborar en código y configurar agentes de IA modernos.

<Steps>
  <Step number="1" title="Instala Git según tu Sistema Operativo">
    Selecciona la pestaña de tu sistema operativo y ejecuta el comando oficial recomendado:

    <OsTabs
      windowsCmd="winget install --id Git.Git -e --source winget"
      windowsDesc="Ejecuta en PowerShell (recomendado para Windows 10/11):"
      macosCmd="brew install git"
      macosDesc="Usa Homebrew en la terminal de macOS:"
      linuxCmd="sudo apt update && sudo apt install git -y"
      linuxDesc="Para distribuciones basadas en Debian/Ubuntu:"
    />
  </Step>

  <Step number="2" title="Configura tu Identidad Global">
    Git necesita saber quién eres para firmar tus cambios. Ejecuta los siguientes dos comandos reemplazando con tus datos reales:

    <CodeBlock
      filename="config-identidad.sh"
      language="bash"
      code="git config --global user.name &#34;Tu Nombre&#34; &amp;&amp; git config --global user.email &#34;tu-correo@ejemplo.com&#34;"
    />
  </Step>
</Steps>

<Verify
  command="git --version"
  expectedOutput="git version 2.53.0.windows.2"
  description="Abre una nueva ventana de terminal y ejecuta el comando de comprobación. Debes observar un número de versión superior a 2.40.0:"
>
  Si ves la versión en pantalla, ¡todo listo! Tu sistema ya puede clonar y gestionar repositorios de código.
</Verify>

<Callout type="tip" title="Consejo para principiantes">
  Si estás en Windows y acabas de instalar Git, debes cerrar todas las consolas abiertas y abrir una nueva para que reconozca el comando <code>git</code>.
</Callout>
