Node.js es el entorno que permite ejecutar código JavaScript del lado del servidor y es indispensable para la mayoría de herramientas y servidores del protocolo MCP (Model Context Protocol).

<Steps>
  <Step number="1" title="Instala Node.js (Versión LTS Recomendada)">
    Ejecuta el comando oficial correspondiente a tu sistema:

    <OsTabs
      windowsCmd="winget install OpenJS.NodeJS.LTS"
      windowsDesc="En Windows con PowerShell (instala la versión LTS estable):"
      macosCmd="brew install node@22"
      macosDesc="En macOS usando Homebrew:"
      linuxCmd="curl -fsSL https://deb.nodesource.com/setup_22.x | sudo -E bash - && sudo apt install -y nodejs"
      linuxDesc="En Ubuntu/Debian mediante el repositorio NodeSource oficial:"
    />
  </Step>

  <Step number="2" title="Habilita e Instala pnpm">
    Node.js incluye la herramienta `corepack` para activar gestores modernos como `pnpm` sin instalaciones adicionales:

    <CodeBlock
      filename="instalar-pnpm.sh"
      language="bash"
      code="corepack enable &amp;&amp; corepack use pnpm@latest"
    />
  </Step>
</Steps>

<Verify
  command="node --version; pnpm --version"
  expectedOutput="v24.14.0 / 10.32.1"
  description="Comprueba que Node y pnpm responden con sus versiones activas:"
>
  Cualquier versión de Node superior a v20.x y de pnpm superior a v9.x es completamente compatible.
</Verify>

<Callout type="aviso" title="Nota sobre versiones">
  Recomendamos utilizar siempre versiones LTS (Long Term Support) de Node.js para asegurar máxima estabilidad con los SDKs de agentes.
</Callout>
